###################################################################################


This folder contains the code used to demonstrate the implementation of functional joint model in a simulation setting for 

"Bayesian estimation of partial functional Tobit censored quantile regression model"

by Chunjie Wang , Zhexin Lu, Chuchu Wang and Xinyuan Song*.

There are three main codes:
 "code_1" for  evaluating the estimation performance in the presence of right-censoring data;  
 "code_2" for  evaluating the effectiveness of utilizing FPCA for high-dimensional imaging data in feature extraction and parameter estimation.
